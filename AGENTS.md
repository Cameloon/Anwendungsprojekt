# AGENTS.md

## Stack

- **Frontend:** Vite + React 18 + TypeScript (very loose: `strict: false`, `noImplicitAny: false`, `strictNullChecks: false`, `noUnusedLocals: false`)
- **Backend:** Convex (26 tables in schema)
- **UI:** Tailwind CSS + shadcn/ui + Radix UI primitives
- **Auth:** Clerk (JWT, `convex/auth.config.ts`) with automatic demo mode fallback
- **Build tool:** `@vitejs/plugin-react-swc` (SWC, not Babel)
- **Package manager:** Bun (npm also works)
- **Testing:** Vitest — jsdom + @testing-library/react (frontend), `convex-test` + `edge-runtime` (Convex backend, `tests/convex/`)
- **Linting:** ESLint (flat config `eslint.config.js`)
- **Path alias:** `@/` → `./src/`

## Key Commands

```bash
bun install                         # Install dependencies
bun dev                             # Dev server on port 8080
bun build                           # Production build
bun build:dev                       # Dev mode build
bun preview                         # Preview production build
bun lint                            # ESLint (flat config)
bun test                            # Vitest run (headless)
bun test:watch                      # Vitest watch mode
bun run update-test-status          # Run tests + update docs/test-uebersicht.md
npx convex dev                      # Sync Convex schema/functions (run in parallel to bun dev)
npx convex deploy                   # Production Convex deploy
```

Dev requires **two parallel terminals**: `bun dev` (port 8080) + `npx convex dev`.

## Conventions

### TypeScript & Linting
- TypeScript is intentionally very loose. No `typecheck` script exists. Unused locals/params do not fail.
- ESLint has `@typescript-eslint/no-unused-vars: off` — unused vars never cause failures.

### Dev Server
- HMR overlay disabled (`vite.config.ts`: `overlay: false`). Error overlay won't appear in browser.
- Two parallel terminals: `bun dev` + `npx convex dev` (both must run simultaneously).

### Demo Mode
`IS_DEMO` in `src/lib/demoMode.ts` auto-detects when `VITE_CLERK_PUBLISHABLE_KEY` or `VITE_CONVEX_URL` is missing. When true, the app uses localStorage for dummy auth/profile instead of Clerk/Convex. `useAuth` hook in `src/hooks/useAuth.tsx` switches between `useDemoAuth()` and `useClerkBackedAuth()` via `IS_DEMO`.

### Auth & Access Flow
1. Clerk sign-up → `EnsureProfile` creates Convex profile with `role: "user"`
2. Onboarding → `OnboardingDialog` forces `displayName`, `studienfach`, `matrikelnummer`, `hochschule`, `kurs`
3. After onboarding → profile `status: "pending"`, user sees "Freischaltung ausstehend"
4. Admin approves/rejects via `admin.ts` mutations → `status: "active"` / `"rejected"`
5. Admin users (`role: "admin"`) bypass approval → always `"active"`
6. `ProtectedRoute` uses `getAccessStatus` query → shows onboarding/pending/rejected/active states
7. Navbar adapts: before approval only "Zugang freischalten", after full nav

### Convex
- **Always read `convex/_generated/ai/guidelines.md`** before writing Convex code (overrides training data). Generated by `npx convex dev` — doesn't exist in a fresh clone until that has run.
- Available skills: load via `skill` tool or run `npx convex ai-files install` (see `.agents/skills/`)
- `ctx.auth.getUserIdentity()` for server-side auth; NEVER accept userId as function arg
- Profile fields: `kurs` is uppercased on save; `role` defaults to `"user"`
- `convex/migrations.ts` collections one-off migrations run via `npx convex run migrations:<name>`. Already applied to current dev deployment — kept for reference.

### Testing
- Tests in `tests/` (not `src/test/`) — `tests/**/*.{test,spec}.{ts,tsx}`
- Setup file: `tests/setup.ts` (mocks localStorage, matchMedia, scrollIntoView; guarded with `typeof window !== "undefined"` for Convex backend tests)
- Convex backend tests in `tests/convex/` use `convex-test` (`convexTest(schema)`, `t.withIdentity({ subject })`) — files start with `// @vitest-environment edge-runtime`; requires `server.deps.inline: ["convex-test"]` in `vitest.config.ts`
- `bun run update-test-status` runs all tests and writes JSON report, then `scripts/update-test-status.ts` parses it into `docs/test-uebersicht.md`

### Layout
- Navbar: `fixed top-0`, pages use `pt-32 md:pt-24`
- Footer: sticky flexbox (not fixed)
- Mobile navbar ~108px due to bottom nav strip
- 1600ms splash screen on boot (`SplashScreen` component)
- Tailwind custom fonts: `Space Grotesk` (heading), `Inter` (body)

### Deployment
- Docker build (`Dockerfile`, `docker-compose.yml`) passes `VITE_CLERK_PUBLISHABLE_KEY`, `VITE_CONVEX_URL`, `VITE_CONVEX_SITE_URL` as build args
- Served via nginx (SPA fallback: `try_files $uri /index.html`)
